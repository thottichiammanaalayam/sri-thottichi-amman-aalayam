## 🚀 Deployment
Deployed via **Vercel** / **GitHub Pages**

### GitHub-ல் பதிவேற்றம் செய்ய (Commands):
```bash
git init
git add .
git commit -m "Initial commit - Sri Thottichi Amman Temple Website"
git branch -M main
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```

## 🛠️ How to Edit
1. Each section has its own CSS file in `css/`
2. Edit only the file you need
3. Push to GitHub → Auto-deploys on Vercel / GitHub Pages
